# AETHER Admin Frontend

Beautiful, modern admin interface for AETHER Core.

## Features
- Always-visible AI Command Bar (the killer feature)
- Dark premium design with purple accents
- Fully responsive
- Real-time dashboard
- All main sections: Products, Orders, Emails, Suppliers, Autonomous, History, Settings

## How to run

```bash
npm install
npm run dev
```

Frontend runs on http://localhost:5173

Backend must be running on http://localhost:9000 for the Command Bar to work.
