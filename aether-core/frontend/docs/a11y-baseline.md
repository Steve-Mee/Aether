# A11y baseline (axe-core)

Generated by `npm run test:a11y` — strict gate on 9 core routes; `/login` report-only.

**Core routes (strict CI gate):** `/`, `/command-center`, `/approvals`, `/insights`, `/timeline`, `/suppliers`, `/settings`, `/emails`, `/products`

**Deep routes (report-only):** `/login`

**Tags:** `wcag2a`, `wcag2aa`, `wcag21aa`

## Violation summary

| Phase | Scope | Result |
|-------|-------|--------|
| Fase 1 | 7 routes | ~1 serious/route (color-contrast) — report-only |
| Fase 2 | 7 routes | **0 serious/critical** — CI gate enabled |
| Fase 3 | 9 routes + SR/focus | **0 serious/critical** on core routes; live regions, focus restore, list semantics |
| Fase 4 | SR channel + focus e2e | Single approval SR path; `skipAnnounce` on inbox; focus-restore `toBeFocused()` e2e |

**Fase 3 improvements:** assertive error announcements, inbox info `announce()`, notification bell↔popover anchor, Radix Sheet for AutonomyTraceDrawer, UserMenu Popover, SettingRow `aria-describedby`, SegmentedControl arrow keys, supplier form validation.

**Fase 4 improvements:** approval success via banner only (`skipAnnounce` on info notifications when page owns feedback), Command Center status via inline `aria-live` card (no duplicate `announce()`), Activity list semantics + single tab-stop, focus-restore e2e with `toBeFocused()`.
