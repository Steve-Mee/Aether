# AETHER Core Backend

The living, self-evolving AI e-commerce organism.

## Quick Start

1. Copy `.env.example` to `.env` and update your database URL
2. Run `npm install`
3. Run `npm run prisma:migrate`
4. Run `npm run dev`

Backend will be available at http://localhost:9000
