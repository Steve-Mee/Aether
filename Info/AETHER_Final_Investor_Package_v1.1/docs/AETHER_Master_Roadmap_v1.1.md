```

   ↓

   ↓
Data Layer: PostgreSQL + TimescaleDB + Weaviate (vector) + Neo4j (graph)
   ↓
Event Bus (Apache Pulsar) + Federated Learning Layer
   ↓
Attribution & Billing Engine (DoWhy + EconML + Snowplow)
   ↓
Payment Abstraction Layer + AETHER Pay (Adyen/Stripe powered)
```

### Appendix E: PoC Specificatie — AETHER Mail v0.5 (NIEUW v1.1)
**Doel**: Volledig functionerende unified inbox voor merchants, volledig beheerd door **lokale AI** (privacy-first). Geen data naar externe LLM providers voor gevoelige communicatie.

**Scope v0.5 (pilot met 50 merchants)**:
- IMAP + SMTP integratie (Gmail, Outlook, custom IMAP)
- Lokale LLM (Ollama Llama 3.1 70B of fine-tuned model) met tool-calling
- Auto-classificatie (klantenservice / leverancier / finance / intern / spam) met >85% accuracy
- Reply drafting met volledige context (order status, klantgeschiedenis, vorige mails via Medusa + vector search)
- Low-risk auto-actions (tracking info sturen, retourlabel genereren, simpele FAQ antwoorden)
- High-risk proposal queue in Admin (merchant keurt goed/af)
- Volledige audit log + rollback

**Technische Architectuur**:
- Python microservice (FastAPI) met secure IMAP client (aioimaplib)
- LangGraph agent flow: Email In → Parse → Classify → Context Retrieval (Medusa + Weaviate) → Draft/Act → Human Review (indien nodig) → Send
- Container: Docker met --network=none voor LLM inference + gecontroleerde outbound (alleen SMTP/IMAP van merchant)
- Medusa integratie: Custom module + events (order.updated → trigger context refresh)

**Veiligheid & Compliance (First Principles)**:
- Air-gapped inference container (geen internet behalve gecontroleerde IMAP/SMTP)
- Alle prompts + outputs gelogd (onherroepelijk)
- Confidence threshold: <85% → altijd human review
- Merchant kan “Never auto-respond to X” configureren
- GDPR: Data blijft 100% bij merchant; exporteerbaar

**Success Metrics v0.5**:
- >70% mails auto-geclassificeerd
- <20% escalation naar human
- Merchant tijd bespaard: >4 uur/week
- 0 data leaks / security incidents

**Volgende stap na v0.5**: Multi-account support + supplier negotiation templates + voice replies.

(Zie volledige implementatie in `AETHER_Mail_PoC.md` — te schrijven in Fase 1 sprint 1)

### Appendix F: PoC Specificatie — Supplier Intelligence Agent v0.5 (NIEUW v1.1)
**Doel**: AI agent die veilig en autonoom leveranciers-websites monitort, productinformatie extraheert en prijs/voorraad/nieuwe producten synchroniseert met Medusa — met minimale merchant inspanning en maximale veiligheid.

**Scope v0.5 (pilot met 20 merchants + 5 leveranciers)**:
- Per leverancier configureerbare “crawl profile” (start-URLs, update frequentie, approval policy)
- Sandboxed browser automation (Playwright in isolated Docker container met stealth plugins)
- Multi-modal lokale LLM (tekst + vision) voor product page parsing (titel, prijs, stock, variants, images, beschrijving, levertijd)
- Structured output via Instructor / Pydantic → directe mapping naar Medusa Product / Variant / Inventory
- Diff engine: “Wat is er veranderd?” → proposal in Admin
- Auto-sync voor inventory & prijs (trusted suppliers) of approval queue (nieuwe producten / grote wijzigingen)
- Respect robots.txt + rate limiting + exponential backoff

**Technische Architectuur**:
- Scheduler (Celery / APScheduler) → crawl job per supplier
- Playwright container (headless, user-agent spoofing, proxy optioneel)
- Vision + text LLM (lokale LLaVA of Qwen2-VL) + structured extraction
- Medusa plugin: custom “supplier_sync” module met draft products + inventory adjustment API
- Event: supplier.price_changed → trigger Pricing Agent + Attribution recalc

**Veiligheid & Compliance (First Principles — Boundary Push)**:
- **No login scraping**: Alleen publieke pagina’s (of merchant-provided credentials in encrypted vault)
- Strict allowlist per merchant (alleen goedgekeurde domains)
- Volledige logging van elke request + screenshot (voor audit)
- Legal: Automatische disclaimer in logs + merchant moet akkoord gaan met leverancier ToS bij onboarding
- Container isolation: Geen persistent disk, max 5 min runtime per job, killed on anomaly
- Rate limit: Max 1 request / 3 sec per domain, global throttle

**Success Metrics v0.5**:
- >90% accurate prijs detectie
- >80% accurate stock status
- >70% nieuwe producten correct gemapped
- 0 security incidents / ToS violations
- Merchant tijd bespaard: >6 uur/week per leverancier

**Radicale uitbreiding (Fase 2+)**: AI ontdekt automatisch nieuwe leveranciers via niche search + onderhandelt via mail (binnen merchant marge limieten).

(Zie volledige implementatie in `AETHER_Supplier_Agent_PoC.md` — te schrijven in Fase 1 sprint 2)
